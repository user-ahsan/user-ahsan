### Ahsan Ali

Building automation pipelines, scrapers, and full-stack apps from Lahore, Pakistan.

I mostly work on taking stuff that runs on manual data entry — spreadsheets, WhatsApp threads, Google Sheets — and turning it into software. Sometimes that's a Flutter app on 6 platforms. Sometimes it's an n8n workflow that replaces an intern.

**Currently obsessed with:** [Collabryx](https://github.com/user-ahsan/collabryx) — AI-powered networking platform. I built the whole matching engine on top of pgvector, generating 384-dim embeddings with Sentence Transformers, with a FastAPI microservice feeding into a Next.js frontend that has 3D visualizations, real-time messaging, and rate limiting / bot detection / RLS across the board.

**Also built:**
- [FDH Order System](https://github.com/user-ahsan/fdh) — offline-first order management for a tailoring shop. Flutter, syncs to Supabase when the device comes back online. Generates PDF job sheets and prints to thermal printers. Built a corruption recovery system because data loss is not an option for these clients.
- [Google Maps Scraper](https://github.com/user-ahsan/Google-Maps-Scrapper) — Python + Playwright scraper with human-like scrolling, rotating user agents, auto-retry, dedup cache, and live Google Sheets export. Has a GUI for non-technical users.
- [LinkedIn Auto-Poster](https://github.com/user-ahsan/linkedin-autoposter-googlesheet) — reads from Sheets or Markdown, posts via Playwright browser automation. Full CI pipeline.
- [CRM Platform](https://github.com/user-ahsan/crm) — B2B CRM frontend with deeply nested table views, team calendar, role-based UI.
- A multilingual AI support agent that detects Roman Urdu vs English on WhatsApp and routes through language-specific e-commerce prompts with conversation memory.
